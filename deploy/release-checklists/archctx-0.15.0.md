## Changes

- **#574:** CodeGraph facts use the in-process read-only SDK; CLI-era contracts and adapter surfaces are retired (ADR-0058).

## Release notes

Use this section as the GitHub Release notes file.

**archctx / archctx-contracts 0.15.0 moves CodeGraph reads to an in-process read-only SDK and removes CLI-era contracts. Upgrade both packages together and review the compatibility notes below.**

CodeGraph changes (#574, ADR-0058):

- CodeGraph facts are read through an in-process read-only SDK session. `codegraph sync` is the only CodeGraph process started by archctx; `complete` runs it once.
- `buildTaskContext` uses `findRelevantContext` and `searchNodes`; the code-context digest and observed views change once. Impact callers and callees are typed call edges.
- A source edit during a ready-index read is refused. `codegraph sync` failures report one message form. A `withReadyCodeGraphIndex` `code-facts-unavailable` refusal carries `action: inspect-diagnostics` and `retryable: false`.
- ADR-0058 Decision 4 records that the provider can rewrite a missing, unreadable or stale CodeGraph-generated `.codegraph/.gitignore` to its default; a user-authored file is left untouched. SQLite may create WAL and SHM sidecars during read-only opens.

Import coverage (#585):

- The default import-node cap is 64,000. Above it, the deterministic prefix is reported with `importNodeLimitExceeded`. The SDK reads the whole import population in process, so the cap bounds reported coverage, not read memory.

Repository CI (#603): pull requests and pushes to main run an impact plan; explicit release validation runs the complete platform and Node matrix. This is repository-internal and does not change the product.

### Compatibility notes

Upgrade `archctx` and `archctx-contracts` together. Consumers including repo-harness should review their pinned version and update integrations for these breaks:

- The three `code-facts-snapshot-*` failure reasons are removed. `CodeFactsPort` no longer exposes `getImpact`, `getCallers` or `getCallees`; `ImpactQuery` and `NormalizedImpact` are removed.
- `CODE_FACTS_ISSUE_MESSAGES` no longer includes `not-initialized` or `worktree-mismatch`. The projection handshake no longer includes `preSyncStatusDigest`, `postSyncStatusDigest` or `syncDigest`.
- `CodeGraphCliProvider` is renamed `CodeGraphSdkProvider`, with no alias. `projectionCodeGraphStatusIssues`, `CodeGraphProjectionStatusV1` and the `ProjectionCodeGraphStatusIssue*` types are removed. `loadCapabilityCodeGraphProjectionInputs` no longer takes a `readOnly` option.
