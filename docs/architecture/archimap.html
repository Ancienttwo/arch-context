R-A1 · Medium · structure

Import cycle core ↔ renderer

packages/core and packages/core/projection-engine import each other (5 vs 2 value imports), so neither workspace slice can be reasoned about alone. No gate checks cycles inside a workspace. Direction: let the engines consume the renderer through a contracts port, or fold the cycle into one slice deliberately.

packages/core/projection-engine/src/index.ts · measure.ts at eadea4a9
R-A2 · Medium · measurement blind spot

8 unresolved workspace imports from tooling

Readback scripts import workspace test factories via subpaths that package exports do not declare, so the import matrix under-counts tooling → runtime edges. Direction: declare the test-factory subpath in local-runtime exports, or import through the package root.

scripts/architecture-ledger-al10-chaos-security-readback.ts · @archcontext/local-runtime/test/*
